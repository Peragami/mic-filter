# ノイズ除去とEQの種類（mic-filter 採用候補つき）

## ノイズ除去 — 方式で分ける
| 方式 | 得意なもの | 遅延 | 重さ | 採用 |
|---|---|---|---|---|
| ノイズゲート／エキスパンダー | 無音時の環境音全般（ファン、部屋鳴り） | 0 | 最軽量 | ◎ 採用済み。ただし喋ってる間のノイズは消えない |
| ハイパス／ローカット | ゴーという低音、机の振動、息の吹かれ | 0 | 最軽量 | ◎ |
| ノッチ（ハム除去） | 電源ハム音 50/60Hz とその倍音 | 0 | 最軽量 | ◎ 候補。小さい音源で効く |
| デクリック／リップノイズ除去 | 唇のペチャ音、口のクリック、キーボードのカチ音 | 見越し1.3〜2.7ms | 軽い | ◎ 希望あり |
| ディエッサー | サ行のキンキン（歯擦音） | ほぼ0 | 軽い | ○ 候補。方式はダイナミックEQ |
| デポップ | パ行のボフッ（破裂音） | ほぼ0〜小 | 軽い | ○ HPF＋検出で実現 |
| スペクトル系（スペクトル減算／Wiener／スペクトルゲート） | 定常ノイズ全般（エアコン、PCファン） | FFT窓ぶん約10〜20ms | 中 | △ 遅延とトレードオフ |
| AI系 RNN（RNNoise） | 定常＋ある程度の非定常ノイズ。Discordのノイキャンの土台系 | フレーム約10ms級 | 軽〜中（CPUのみで可） | △ 有力だが遅延増 |
| AI系 深層学習（DeepFilterNet、Krisp、RTX Voice等） | 他人の声、テレビ、食器音まで。今一番強い | 約10〜30ms | 重い（モデル／GPU） | △ 最軽量方針とは逆 |
| 適応フィルタ（ANC系） | 参照マイクがある場合の環境音 | 小 | 中 | × 単一マイクでは不向き |
| ディリバーブ | 部屋の反響 | 大きめ | 重い | × AI寄り、本用途では優先低 |

「ノイズ除去」単体で買うと大抵スペクトル系かAI系を指す。ゲートは除去ではなく「無音時に閉じる」もの。

### AIなしでどこまで削れるか（2026-11-08 合成信号でシミュレーション実測）
定常ノイズ（ホワイトノイズ）＋声もどき信号でスペクトル減算（FFT512、ノイズ学習あり）を試した参考値：
- 無音区間のノイズ：**-25.7dB**（理想条件の定常ノイズでの値。実環境では 10〜20dB 級が現実ライン）
- 発話区間：ノイズ＋歪みの合計で **約4.8dB改善**止まり（引くほど声も歪む＝「水っぽさ・ロボ声」の副作用が上限を決める）
- ゲート併用なら無音区間は体感ほぼ無音まで落とせる
- 効かないもの：他人の声、テレビ、犬の鳴き声など「声と同じ時間・周波数に居る非定常音」。分離が要るのでAIの領分
- 発話中にも効かせる遅延0の手はマルチバンド・エキスパンダー（帯域ごとにゲート）。スペクトル系より穏当だが、FFT遅延（512で10.7ms窓）を払わずに済む

## EQ — 形（バンドの種類）
- **ハイパス／ローパス**：ある周波数から先を切る（ローカットはこれ）
- **ローシェルフ／ハイシェルフ**：低域／高域をまとめて持ち上げ・下げ
- **ピーキング（ベル）**：中心周波数まわりを山／谷型に。声のこもり取り等
- **ノッチ**：ごく狭い谷。ハム音や共鳴のピンポイント除去
- **バンドパス**：帯域だけ通す（電話声みたいな加工用）
- **ティルト**：中心点でシーソー式に低域⇔高域を傾ける

## EQ — 制御の方式
| 方式 | 特徴 | 遅延 |
|---|---|---|
| パラメトリックEQ | 周波数・ゲイン・幅(Q)全部可変。マイク調整の標準。うちの実装はこれ（IIR） | 0 |
| セミパラメトリック | Q固定で周波数とゲインだけ | 0 |
| グラフィックEQ | 帯域固定でスライダー列（10/31バンド等）。直感的だが細かく狙えない | 0（IIR時） |
| ダイナミックEQ | 音量に応じてバンドが動く。ディエッサーや共鳴抑えはこれ | ほぼ0 |

## EQ — 位相の方式（遅延の分かれ目）
| 方式 | 特徴 | 遅延 |
|---|---|---|
| 最小位相（IIR） | 普通のEQ全部これ。軽い | 0 ◎ |
| リニアフェーズ（FIR） | 位相がずれないが窓ぶん遅れる。ミックス／マスタリング用 | 数十ms ✕ リアルタイムマイクには不採用 |

## このアプリの推奨セット
EQ：パラメトリック5バンド相当（HPF＋ローシェルフ＋ピーキング×3…は現状構成、必要ならピーキングを増やす）＋ノッチ1つ
ノイズ除去：ゲート＋デクリック（リップ）必須、ハムノッチとディエッサーは軽いので追加可。
スペクトル／AIは「遅延を払ってでも定常ノイズを喋ってる間も消したい」場合だけ追加する。
